# الرفيق — الصديق الأمين

تطبيق ويب + PWA لإدارة المصروفات والدخل بطريقة شات تفاعلي بالعربية.

## المميزات
- واجهة عربية RTL مع شات ذكي لفهم المصروفات بلغة طبيعية
- استخراج المبلغ والفئة وطريقة الدفع تلقائياً
- شاشة مراجعة وتأكيد قبل الاعتماد
- لوحة ملخص مالي (رصيد، وارد، مصروف، أعلى الفئات)
- سجل عمليات قابل للحذف
- تخزين محلي (localStorage) + جاهزية كاملة لربط Supabase
- PWA قابل للتثبيت على الموبايل

## التشغيل

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## ربط Supabase (اختياري)
1. أنشئ مشروع على https://supabase.com
2. نفّذ ملف `supabase/schema.sql` في محرر SQL
3. انسخ `.env.local.example` إلى `.env.local` وأضف المفاتيح
